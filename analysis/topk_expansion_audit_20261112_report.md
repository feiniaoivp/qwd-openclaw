# Top-K 扩缩受控审计：trend_up regime_top_k 30 vs 15/20/25（2026-11-12）

> 触发：`/signal_evidence_audit`（用户未指定假设，按推荐项执行 Top-K 扩缩审计）。
> 前置证据：`data/universe/stress_test_20261111.json`（观测性）——K30 均值 +23.4bp vs K15 +17.3bp，
> 但尾部(16-30)去当日最优2只后 −128.8bp（头部依赖极重）、分年符号翻转（+74/−11/+65/−0.0/+15/−3.9）。
> 本审计将其升级为**预注册判据的受控多臂对照**。

## 数据与口径

- 数据：`data/universe/score_rows_3d.pkl` 1,041,733 行，2021-04-13 → 2026-11-09，1,351 交易日。
- 覆盖先验（2026-11-12 实测）：score 覆盖 100%，ex5 覆盖 100%（2026 年 97.55%，尾部 5d 收益未满属正常）；
  trend_up 349 日（分年 92/43/39/44/99/32）。**样本充足，立项。**
- 选择语义与生产 `analysis/signal_scoring.py` 一致：
  1. 按 regime 取 `eff_top_k`（trend_up=30 / sideways=15 / trend_down=15 / high_vol=5）
  2. sideways 双条件地板：top1<90 或 top5_mean<80 → 当日候选归零
  3. 硬门槛：`bb_pos∈[0.15,0.92]`（**bb_pos 缺失=放行，与生产 fail-open 一致**）且 `score≥45`（生产 MIN_SCORE）
  4. 按 score 降序取前 min(K, n_gated) 只，日超额 = 选中票 ex5 的 nanmean

## 臂设计（逐日同池，唯一差异 = trend_up 的 K）

| 臂 | trend_up K | 其余 regime | 角色 |
|---|---|---|---|
| A | **30**（现产） | 不变 | 基线 |
| B15 | 15 | 不变 | 回退候选（前默认值） |
| B20 | 20 | 不变 | 敏感性 |
| B25 | 25 | 不变 | 敏感性 |

## 恒等式断言（违反即 exit 1，拒绝出结论）

- I1：非 trend_up 日，四臂选中集完全一致（max|日超额差| = 0）
- I2：trend_up 日 n_gated ≤ 15 时四臂一致
- I3：trend_up 日 B15 ⊆ B20 ⊆ B25 ⊆ A（收缩嵌套）

## 判据（预注册，跑前写定；跑完只对照标准判读，不挪门槛）

主判据：trend_up 日配对差 Δ = mean(B15) − mean(A)（bp），day-level bootstrap 2000 次 95%CI。
辅助：去头稳健（每日剔除选中集内 ex5 最优 2 只后重算的 Δ）、分年 Δ 同号率。

| 情形 | 判读 |
|---|---|
| Δ ≥ +10bp 且 ≥4/6 年 Δ>0 且 去头Δ ≥ −5bp | **维持 K=30**（现产正确，记录证据，无行为变更） |
| −10bp ≤ Δ < +10bp 或 分年同号 <4/6 | **维持现状 + 观察**（tail_decay observe_only 继续跑），不动 K |
| Δ < −10bp 或 去头Δ < −20bp（CI 排除 0） | **提议收缩 K**（先 observe_only ≥2 周轨迹一致后才改行为，skill 步骤 7） |

中间档 K20/K25 仅作敏感性参考，不单独立项。
样本不足兜底：trend_up 日 <100 或任一年 <20 日 → 声明样本不足以立项（实测 349 日，不触发）。

### 预注册方向勘误（透明记录）

预注册表第 1/3 行的方向标签写反（Δ 定义为 B15−A：Δ≥+10 实为支持收缩到 15 而非「维持30」；Δ<−10 实为维持30）。跑前未发现、跑后不挪门槛——按修正后的算术方向判读如下，勘误本身即披露。

## 结论

**判定：维持 trend_up regime_top_k=30（现产正确），无行为变更。**

1. Δ=−6.9bp 落在 ±10bp 中间带 → 不收缩；CI 含 0，收缩到 15 无显著收益。
2. 分年同号仅 2/6 → K15 的相对优势不稳定，不构成收缩证据。
3. 去头Δ=−58bp：剔除每日最优 2 只后 K30 反而显著优于 K15——与 11-11 观测「尾部 16-30 脆弱」不矛盾（那是 16-30 段自身去头），全臂口径下 ranks 3-30 的分散化收益大于尾部拖累。
4. 11-11 的 K15+60 分门槛对照（+29.5bp）不采纳：60 非生产 MIN_SCORE(45)，且属假设性重参。
5. tail_decay observe_only 继续跑（12.78 阈值仅记录不改行为）；若未来 2 周实盘轨迹显示 top1-top30 gap 持续超阈且候选池质量下降，再凭新证据立项收缩。

**行动项**：无配置变更（regime_top_k.trend_up=30 不动）；本报告与 JSON 归档备查。

# 第二轮（2026-11-12 深究）：内点 K 与条件收缩

触发：第一轮非单调信号（Δ15=−6.9 / Δ20=+2.8 / Δ25=+3.0，相对 K30）→ 最优 K 可能是内点，26-30 段可能拖累；且 tail_decay 条件收缩（gap>12.78 → K15）从未被受控验证。

## 预注册判据（跑前写定）

臂设计（仅 trend_up 日不同，其余同第一轮语义）：

| 臂 | 规则 | 角色 |
|---|---|---|
| A | K=30 恒定 | 基线（现产） |
| B20 / B25 | K=20 / 25 恒定 | 内点检验 |
| C | gap=top1−score[29]（全池≥30行）；gap>12.78 → K15，否则 K30 | 条件收缩（in-sample 阈值，源 distribution_audit P75） |
| D | 阈值改用 2021-2023 段 gap 的 P75 重拟合；仅评估 2024-2026 日 | 半样本环形对照 |

判据：
1. 带分解（K1-5/6-10/.../26-30 各段日均 ex5）：**描述性**，不单独立项。
2. 内点替换（B20 或 B25 取代 30）：需 Δ(arm−A) ≥ +10bp 且 ≥4/6 年 Δ>0 且去头Δ ≥ −5bp；否则维持 30。
3. 条件收缩 C：Δ(C−A) ≥ +10bp 且 CI95 排除 0 且 ≥4/6 年 Δ>0 → 才提议 tail_decay 从 observe_only 转行为变更；CI 含 0 → 维持 observe_only；Δ<−10 → 反向证据（记录并下调收缩建议优先级）。
4. 环形控制：任何行为变更提议必须 D 与 C 在 2024-2026 段同号，否则视为阈值过拟合，不加行为。
5. 附带记录：C 的触发率（gap>12.78 的 trend_up 日占比）。

## 第二轮结果（2026-11-12 23:54，data/universe/topk_round2_audit_20261112.json）

恒等式：非 trend_up 1002 日五臂全等 ✅。C 触发率 26%（89/349）；环形阈值重拟合 2021-23 P75 = 12.86（与 in-sample 12.78 几乎一致，阈值本身稳）。

### 带分解（A 选择集，日均 ex5, bp）

| rank 带 | 1-5 | 6-10 | 11-15 | 16-20 | 21-25 | 26-30 |
|---|---|---|---|---|---|---|

**反直觉核心发现：16-20 段是超额最高带（+44.7bp），26-30 段确实衰减（+3.6bp）但为正。**「尾部 = 负担」的直觉不成立——16-25 是甜点区，砍到 15 恰好把最肥的一段砍掉。

## 第二轮结论

1. **维持 regime_top_k.trend_up=30**：B20/B25 均未达替换门槛；26-30 段虽薄（+3.6bp）但为正贡献，砍掉即损失期望值。
2. **tail_decay 条件收缩不立项**：C 全期 Δ=−0.9bp（零收益），D 环形对照 −5.4bp 且 0/3 年为正——12.78 阈值的「陡峭→收缩」叙事在样本外不成立，属 in-sample 拟合伪信号。observe_only 继续观测，但**下调收缩建议的先验权重**（证据已反向）。
3. 带分解的 16-20 甜点区是**描述性发现**，未预注册不立项；若未来想利用，需新预注册（如 K 从 15 起跳的阶梯臂）。
4. 两轮合计 4 组臂对照全部指向同一结论：**当前 K=30 是稳健选择，无需变更。**
