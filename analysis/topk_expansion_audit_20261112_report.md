  4. 按 score 降序取前 min(K, n_gated) 只，日超额 = 选中票 ex5 的 nanmean

## 恒等式断言（违反即 exit 1，拒绝出结论）

- I1：非 trend_up 日，四臂选中集完全一致（max|日超额差| = 0）
- I2：trend_up 日 n_gated ≤ 15 时四臂一致
- I3：trend_up 日 B15 ⊆ B20 ⊆ B25 ⊆ A（收缩嵌套）

## 判据（预注册，跑前写定；跑完只对照标准判读，不挪门槛）

主判据：trend_up 日配对差 Δ = mean(B15) − mean(A)（bp），day-level bootstrap 2000 次 95%CI。
辅助：去头稳健（每日剔除选中集内 ex5 最优 2 只后重算的 Δ）、分年 Δ 同号率。

| 情形 | 判读 |
|---|---|
| Δ ≥ +10bp 且 ≥4/6 年 Δ>0 且 去头Δ ≥ −5bp | **维持 K=30**（现产正确，记录证据，无行为变更） |
| −10bp ≤ Δ < +10bp 或 分年同号 <4/6 | **维持现状 + 观察**（tail_decay observe_only 继续跑），不动 K |
| Δ < −10bp 或 去头Δ < −20bp（CI 排除 0） | **提议收缩 K**（先 observe_only ≥2 周轨迹一致后才改行为，skill 步骤 7） |

中间档 K20/K25 仅作敏感性参考，不单独立项。
样本不足兜底：trend_up 日 <100 或任一年 <20 日 → 声明样本不足以立项（实测 349 日，不触发）。

## 结论

**判定：维持 trend_up regime_top_k=30（现产正确），无行为变更。**

1. Δ=−6.9bp 落在 ±10bp 中间带 → 不收缩；CI 含 0，收缩到 15 无显著收益。
2. 分年同号仅 2/6 → K15 的相对优势不稳定，不构成收缩证据。
3. 去头Δ=−58bp：剔除每日最优 2 只后 K30 反而显著优于 K15——与 11-11 观测「尾部 16-30 脆弱」不矛盾（那是 16-30 段自身去头），全臂口径下 ranks 3-30 的分散化收益大于尾部拖累。
4. 11-11 的 K15+60 分门槛对照（+29.5bp）不采纳：60 非生产 MIN_SCORE(45)，且属假设性重参。
5. tail_decay observe_only 继续跑（12.78 阈值仅记录不改行为）；若未来 2 周实盘轨迹显示 top1-top30 gap 持续超阈且候选池质量下降，再凭新证据立项收缩。

**行动项**：无配置变更（regime_top_k.trend_up=30 不动）；本报告与 JSON 归档备查。
