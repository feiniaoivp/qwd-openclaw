## 判读标准（预注册）
- Δmean/Δmed ≥ +10bp 且拦截日数 ≥ 60 → 证据支持立项生产 gate
- Δ 在 ±10bp 内 → 无操作意义，维持现状（chip 只展示不拦截）
- Δ < -10bp → 反向证据，cost_bias 高位在这些 regime 反而是动量信号

## 修订（2026-11-12 补充判读）：样本量不足，按预注册标准判「无操作意义」
- **覆盖率结构性限制**：chip 序列仅近 ~400 交易日（2025-03 起），2021~2024 打分行
  无筹码数据 → 全历史有效回测窗只有 2025-03~2026-11。
- **有效样本**：覆盖期内 cost_bias>0.15 触及 top-K 的日子仅 **9 天**
  （trend_up 6 / sideways 2 / trend_down 1），远低于预注册的 ≥60 日门槛建线。
- **方向**：Δ +12.0bp（2025 +12.3 / 2026 +11.2，两年同向）——方向正确但样本不足以立项。
- **根因洞察**：cost_bias>15% 极少出现在 top-K 候选中，因为现有 bb_pos≤0.92 硬门槛
  已实质性承担了「过热拦截」职责（深度获利票大概率 BB 触顶被拦）→
  **chip gate 与既有 gate 冗余，非缺失防线**。
- **结论**：不立项生产 gate。chip 维维持「只展示不打分不拦截」。
  若未来 bb_pos 门槛调整（如放宽至 0.95），需重新跑本实验验证 cost_bias 是否出现独立增量。
