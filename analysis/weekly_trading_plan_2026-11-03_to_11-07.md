## ⚡ 执行纪律铁律（违一条即复盘反省）

### 买入纪律
- [ ] **仅在“缩量回踩支撑 + 分时企稳 + 短周期 MACD 金叉 + 时间窗内”四重确认下买入**
- [ ] **单笔买入 ≤ 仓位上限的 1/2**，分批建仓，不一次性满仓
- [ ] **不追高买在阻力位以上**，若错过低吸等回踩确认，**绝不追涨**
- [ ] **板块/大盘不同步时，个股信号打 7 折执行**（仓位减半、止盈提前）

### 卖出纪律
- [ ] **止盈到位即执行、不幻想、不贪恋、不移动止盈上调**
- [ ] **止损铁律价位触及即时全清仓、不讨价还价、不移动止损下调、不补仓摊薄**
- [ ] **遇次级筹码峰（恒力 17.02/18.23、长电 56.2、招行 46.5、亿纬 52.1）必清仓**
- [ ] **日线长上影/放量顶背离/15 分钟 MACD 顶背离 = 即时减仓/清仓信号**

### 仓位纪律
- [ ] **单票上限**：核心 3%、辅助 2%、观察 1.5%
- [ ] **合计上限**：做多仓位 ≤ 18%、现金/防御 ≥ 82%
- [ ] **周五收盘前**：做多仓位压降至 ≤ 10%（过周末轻仓）
- [ ] **月线收阴/大盘破关键支撑**：下周一开盘前做多仓位压降至 ≤ 5%

### 信息纪律
- [ ] **仅信任**：close_scan_v2 输出、DataRouter 批量历史数据、斐波时间窗、筹码峰分析
- [ ] **不信任**：盘口语音、财经自媒体预测、盘中消息面刺激、直觉
- [ ] **数据异常股（中信金属、巨化股份、思源电气）数据修复前完全回避**

## 🆘 应急预案（极端行情下的执行脚本）

### 场景 A：大盘单日暴跌 > 3%（黑天鹅/系统性风险）
```
触发条件：上证指数单日跌幅 > 3% 或 成交量萎缩至 5000 亿以下
执行脚本：
1. 立即全仓清仓所有做多标的（市价单、不限价）
2. 仓位归零，现金 100%
3. 记录触发时间、指数价位、成交量
4. 进入“防御模式”：仅关注 300ETF/国债逆回购/黄金 ETF
5. 等待：周线级别 MACD 底背离 + 布林下轨企稳 + 量能放大确认 → 逐步建仓
```

### 场景 B：个股闪崩/暴雷（单日跌停/跌幅 > 10%）
```
触发条件：持仓标的单日跌幅 > 8% 或 触发临时停牌/跌停
执行脚本：
1. 竞价/开盘即市价清仓（不等反弹、不补仓）
2. 事后复盘：是否止损纪律失效、是否基本面突变、是否数据源错误
3. 将该标的移入“黑名单” 30 天，期间不再纳入关注池
4. 复盘仓位控制：单票上限是否合理、相关性对冲是否缺失
```
