## 二、发现的问题（按严重度）

### 🔴 P1（影响结论正确性/激进模式意图）

**P1-1 止损冷却不随模式切换重算 —— 激进模式首日买入信号仍被吞**
- `000987 越秀资本 _stop_cooldown_days: 13`（旧 15 天制遗留，10-30 止损时按 15 记录）
- 激进模式 `stop_cooldown_days: 5` 只影响**新**止损（record 时读配置），存量不迁移
- 后果: 今天唯一买入信号（越秀 MACD金叉）被拦到 ~11-16；「分析热闹、成交可怜」在激进首日复现
- 建议: 用户拍板——切换模式时一次性把存量冷却缩到 min(现值, 新配置)（需 /approve 的 state 变更）

**P1-2 030「ATR 仓位微调」是假变量，把健康度地板击穿**
- `_estimate_atr_positions`: entry_price 硬编码 10.0、ATR≈价格3% 硬编码经验值（代码注释自认「实际应接入实时行情」）
- 推导: stop_distance = 2.0×0.3 = 0.6 → avg_atr_pct = 0.6/10 = 6% > 5% 阈值 → 买入乘数永久 ×0.8
- 实测: health 5 → 地板 0.5 → ×0.8 = **0.4**，与标准模式完全相同 → `health_multiplier_floor: 0.5` 被静默击穿
- 这是 10-18 教训「标定阈值前先确认因子是变量还是常量」的同族新实例
- 建议: 接真实 ATR（DataRouter 现成）或删除该微调（乘数回 0.5）

**P1-3 SELL 成交记录 shares 恒 0 —— 台账无法重建持仓史**
- `execute_trade` 卖出写 `append_trade({... "shares": 0 ...})`，实际股数只存 `pos["_last_sell_shares"]`
- 后果: 周报出现「SELL 越秀 ¥6.53 × **0股** 盈亏 -276.78」畸形行；任何基于台账的独立复盘/审计都要靠启发式
- 建议: 卖出台账补 `shares=pos["shares"]`（一行改动）+ 历史不回填

### 🟡 P2（口径断层，系统性偏乐观）

**P2-1 成交模型 = 当日收盘同 bar 成交（前视）**
- 信号由当日日线收盘算出 → 以当日收盘价成交。现实中收盘信号最早次日开盘执行
- 影子台账已在跟踪「次日开盘」买侧口径（10-20 研究: 温和低开 [-2%,-1%) 执行 5日超额 +2.39% 显著），但**主台账未双轨**，卖侧无影子跟踪
- 建议: 主台账加「次日开盘成交」平行账本（影子管线升级），周报加两口径对照列

**P2-2 回测与生产风控不对称**
- `_check_barbell_constraints`（哑铃总额 75/40 + 方向占比上限）只在回测循环调用（portfolio_executor.py:427），生产 15:40 链路未调用
- 当前实际不 binding（27×30k=810k < 任何上限），但回测验证过的约束生产不生效 = 口径分叉温床
- 建议: 接进 run_portfolio_scan（在 _apply_total_expo_cap 之后）

**P2-3 费用模型缺卖出印花税**
- 现状: 双边 0.03% 佣金 + 0.1% 滑点；缺 A 股卖出印花税 0.05%（2023-08 起）
- 后果: 卖出净入系统性高估，抬高高换手策略的模拟收益
- 建议: 卖出侧 cost 加 `sell_value * 0.0005`

**P2-4 agentTurn 监督 cron「部分成功」掩盖内层失败**
- 19:03 daily-supervision-review 状态 ok，但 challenge_review.md 未落盘（22:13 人工补跑才生成）
- agentTurn 型 cron 只要 turn 完成=ok，内层 `&&` 链断裂不反映到 job 状态；cron_noop_guard 只管 command 型毫秒级空转
- 建议: supervision prompt 加「产物存在性自检」（ls 当日 *_challenge_review.md，缺失则补跑并在推送中标注）

**P2-5 空仓卖出信号噪声污染漏斗**
- 信号生成层不检查持仓状态，空仓照样发卖出（上周 8 条未执行中 7 条此类）
- 后果: 漏斗「未执行」被噪声淹没，真实买入拦截原因（冷却/门控）被稀释
- 建议: 报告层标注「空仓卖信号」类别，或生成层跳过

### 🟢 P3（边界与小瑕疵）
- conditional_orders 条件单是一次性孤儿脚本（intraday_alerts_600036_600584.py 写入、无消费方）——「次日条件单」这个最有前瞻性的想法未接进主循环

- execute_trade 内 `max_shares` 计算后未使用（死代码）

## 三、总评

**骨架完整度: 高。** 五层前瞻回路（执行→影子→审计→周报→回测迭代）真实在跑且本周已产出真实发现。
**最大结构性风险: 不是缺回路，而是回路的口径断层**——研究面板（次日开盘口径）vs 主台账（当日收盘口径）、回测（全约束）vs 生产（缺哑铃/方向约束）。若经验总结基于主台账数字，会系统性偏乐观，迭代方向可能被带偏。
**激进模式上线首日即暴露**: 配置全绿 ≠ 行为符合预期（冷却遗留 + 假 ATR 乘数），恰好证明「合成测试 + 逐日对照」的必要性。
