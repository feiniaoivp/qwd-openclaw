# Gap 执行成本重放（2026-10-18）

## 一句话

信号次日开盘执行会被隔夜跳空吃掉 **0.22pp/笔（CI95 [-0.33, -0.13]，显著）**，但**扣掉后超额依然显著为正（+0.48%，CI95 [+0.10, +0.88]）**——信号没有死于执行成本，只是收益打了七折。

## 口径

| 项 | 设定 |
|---|---|
| 信号 | `analysis/research/dual_signal_eval_days.json`，生产同源买入口径（actions 含「买入」），1068 条 |
| 可评估 | 1059 条，2024-04-19 ~ 2026-10-08 |
| 价格 | `data/research_price_cache/{sym}.pkl` 前复权 OHLC，36 只全覆盖 |
| 持有 | 5 个交易日 |
| 理想臂 A | `close(T)` 买入 → `close(T+1+5)` 卖出（回测常用，实盘不可执行） |
| 现实臂 B | `open(T+1)` 买入 → `close(T+1+5)` 卖出（T 日收盘出信号、次日开盘下单） |
| 成本 | B − A（负 = 实盘比回测差） |
| 基准 | **两臂共用同一基准**：`open(T+1) → close(T+1+5)` 全池等权 |

### ⚠️ 首版口径错误（已修，记录留痕）

首版给两臂各配"自然基准"：A 用 `close(T)→close(T+6)`、B 用 `close(T)→open(T+1)`。
两者**持有期完全不同**（6 天 vs 隔夜），基准本身差 **0.92pp**，导致出现自相矛盾的结论：

> 成本均值 −0.22%（实盘吃亏），但现实臂超额 +1.27% > 理想臂 +0.58%

坐实方法：单独统计两条基准的均值，差 0.918pp 恰好解释了这个"反转"。
修复后加了**强制自检** `max|(exB−exA)−cost| ≈ 0`（同基准下该式恒等），不过则 exit 3 拒绝出结论。

**教训（已记 ERR）：多臂对照里每条臂必须减同一个基准，否则臂间差里混着基准口径差，结论会自动反转且看起来合理。**

## 结果

### 1. 全池隔夜跳空分布（22072 个交易日）

均值 −0.024%，中位 −0.013%，**高开占比仅 39.7%**——A 股隔夜跳空本身略偏负（低开略多）。

### 2. 执行成本

均值 **−0.224%**，中位 +0.000%，CI95 **[−0.325, −0.128]** → **显著为负**。

中位数为 0 但均值显著为负，说明成本集中在**左尾**：多数信号 gap≈0（成本≈0），少数高开信号被吃掉 2~3%。

### 3. 按跳空方向分层（关键洞察）

| 分层 | n | gap 均值 | 成本 | 现实臂超额 |
|---|---|---|---|---|
| 低开 < −1% | 101 | −1.79% | **+1.82%** | +1.64% |
| −1% ~ 0 | 372 | −0.44% | +0.44% | +0.65% |
| 0 ~ +1% | 416 | +0.26% | −0.27% | −0.06% |
| 高开 ≥ +1% | 170 | +2.76% | **−2.79%** | +0.72% |

成本完全由 gap 决定（`成本 ≈ −gap`，符合定义）。但注意最后一行：**高开 ≥1% 的信号即便被吃掉 2.79pp，超额仍 +0.72%** —— 说明这批信号本身强度足够。

真正危险的是 `0~+1%` 这一档：**小幅高开 + 超额为负（−0.06%）**，等于信号本身没有 alpha 却还要承担 gap 成本。

### 4. 净收益存活

| 臂 | 均值 | 中位 | CI95 | 判定 |
|---|---|---|---|---|
| 理想（收盘价买） | +0.70% | −0.27% | [+0.31, +1.11] | 显著 |
| 现实（次日开盘买） | +0.48% | −0.43% | [+0.10, +0.88] | 显著 |

**两臂都显著为正 → 信号在真实可执行口径下依然有效**，只是收益从 +0.70% 降到 +0.48%（衰减 31%）。

## 口径局限（必须声明）

1. **未计手续费/印花税/滑点**（A 股双边约 0.1~0.2%）→ 现实收益还要再降，本结论**偏乐观**
2. 均值/中位方向相反（+0.48% vs −0.43%）说明分布右偏，"平均赚钱"靠少数大赢家
3. 样本为双轨信号系统的买入信号历史，不代表其他信号源
4. `open` 为前复权开盘价，除权日可能有偏差
5. 未考虑涨跌停无法成交、成交量不足等执行约束

## 生产含义

**不需要改动任何执行逻辑**——现有 `portfolio_core` 已经是"信号当日生成、次日执行"的口径吗？需要确认。但以下值得做：

1. **回测报告应统一标注口径**：所有用 `close(T)` 入场的回测结果，实际收益应打折约 0.22pp/笔
2. **`0~+1%` 微幅高开档位是负期望**，可考虑给该档加执行折扣（但样本仅 416 条、超额 −0.06% 接近 0，证据强度不足以直接改规则）
3. 暂不据此修改信号，先观察
