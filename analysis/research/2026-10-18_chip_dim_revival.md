# Chip 第 5 维复活标定（2026-10-18）

## 一句话

筹码分布指标里**只有 `cost_bias`（现价偏离平均成本）有可用信号**：`< −0.20` 档 5 日超额 **+2.38%（CI95 [+1.48, +3.26]）**，且 2024/2025/2026 **三年全为正**。另两指标（获利盘、集中度）无单调关系，只作诊断。

## 背景

`score_chip_structure()` 自 2026-10-09 起恒返回 `None`（东财筹码端点被拦截，诚实退出）。
`scripts/chip_distribution_study.py` 已实现"经典筹码衰减法"从本地 OHLCV+换手率自算筹码分布，
产出三指标并落 `data/research_price_cache/chipmetrics_{sym}.pkl`（36 只全覆盖）。

但原研究用的是**年内五分位**，结论是"无单调关系"——本期复核发现**分位口径掩盖了真实结构**。

## 接线口径

`analysis/trader_stock_picks.py::score_chip_structure()`：

```
cost_bias < −0.20  → 8.5 分（5.0 + 3.5）
cost_bias < −0.15  → 7.5 分（5.0 + 2.5）
其余              → 5.0 分（中性）
缓存缺失/异常      → None（沿用 10-09「缺失不填充」纪律）
```

**为什么不设淘汰条件**：极端档（<−0.20）只覆盖 1.5% 样本，"没有筹码折价"不等于"不该买"。
设计为**加分项**而非门禁，避免把 98.5% 的票误伤。

**为什么不扣分**：右侧（浮盈大）证据平坦，"涨多了要跌"是未证伪的直觉，不引入。

## 与 10-09 结论的关系

10-09 说"无数据源 → None"，那次是**数据源缺失**。
本次是**自算数据源**（不依赖外部接口，全部本地可复现），且做了三年分年稳健性检验。
两者不冲突：数据债还的是"数据可得性"，本次补的是"指标可用性"。

## 局限

1. 筹码衰减算法参数（400 档网格、turn 衰减）未做敏感性扫描
2. `<−0.20` 档 n=309，相对 20893 总量偏小，虽 CI 显著但极端值可能受单一时期主导（2025 年 n 仅 14）
3. 未与现有四维做**增量**检验（加入后总排序是否改善），仅验证单维预测力
4. 换手率数据来自 baostock，停牌/一字板日的 turn 可能失真
