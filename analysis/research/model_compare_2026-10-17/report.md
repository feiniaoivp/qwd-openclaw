## 关键发现

1. **同数据三种裁决**（看空/中性/中性），与 studio README 的比亚迪三模型实验同构——差异来自模型风险偏好，不是数据。**动作层却高度一致：三者全给「空仓/观望」**。启示：看简报先看动作层共识，标签（看多/看空）层噪声大。
2. **Qwen（19:35 简报现役模型）保真度最高**，且是唯一识别「金力永磁加权-0.8 为 9 只减仓票最强」的（实测正确）。速度最慢（2m20s）但 600s timeout 富余。**结论：维持 Qwen，不换**。
3. **Vision-Exp 不适合 brief job**：快但格式不合规（加粗/HTML 实体）、TIMING 两个时间戳完全相同（疑似未真实执行 date）、且历史上有工具参数破坏记录。仅作快草稿用途。
4. **系统性歧义「减仓60%」**：030 裁决「减仓(置信度60%)」被 GLM 明确误读为减仓幅度；Qwen/Vision-Exp 的缩写也有同风险。→ 已修入 19:35 job prompt 步骤 6a（必须写全「030裁决减仓(置信度60%)」）。
5. **归类漂移**：Qwen 把久立特材（特钢管材）归入电网板块。→ 已修入 prompt 步骤 6b（归类照原文，统计概括逐只核对）。
