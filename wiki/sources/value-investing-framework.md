## 一、护城河五大基因（晨星/Morningstar 框架）

| 基因 | 核心判断标准 | 典型案例 | 量化指标 |
|------|--------------|----------|----------|
| **1. 无形资产** | 品牌溢价、专利保护、监管牌照 | 茅台(品牌)、辉瑞(专利)、烟草/博彩(牌照) | 毛利率>40%、ROE>20%、定价权强 |
| **2. 转换成本** | 客户更换成本极高（金钱/时间/数据/生态） | 苹果生态、微软Office、SAP/甲骨文、核心银行系统 | 客户留存>90%、涨价不流失 |
| **3. 网络效应** | 用户越多价值越大，边际成本趋近零 | 微信、支付宝、美团、Visa/万事达 | 用户规模指数级、市场份额>60% |
| **4. 结构性成本优势** | 难以复制的低成本（非烧钱堆产能） | 丰田TPS、力拓/必和必拓优质矿山、Costco会员制 | 单位成本<竞争对手20-30%、全周期盈利 |
| **5. 有效规模** | 市场天然只容纳1-2家，新进入致双输 | 小城市机场、区域管道、特定铁路 | 稳定现金流、增长有限、估值适中 |

**评分卡（满分100）：** 每基因 0/1/2/3 分 → ≥60 分为宽护城河，40-60 窄护城河，<40 无护城河

## 二、竞争 vs 垄断：彼得·蒂尔核心洞见

| 误区 | 真相 |
|------|------|
| “自由竞争 → 熬成垄断 → 成为牛股” | 伟大企业在**自由竞争期就展现高ROE/高估值**；垄断是**结果**非原因 |
| “堆产能、烧钱、卷规模”能赢 | 完全竞争长期利润趋近零；**逃离竞争、开辟新赛道**才是商业秘诀 |
| “高端产业”必然好 | 波音(高端)ROE惨 vs 安踏(低端)ROE 20-30% —— **产业不分高低，只分挣钱辛苦不辛苦** |

**投资启示：**
- 寻找**从Day 1就写着反竞争基因**的公司
- 回避：核心逻辑=堆产能/烧钱/同质化卷死对手的赛道（面板/光伏/新能源车）
- 关注：商业模式创新（麦当劳标准化、沃尔玛供应链、星巴克第三空间、Costco精选SKU）

## 三、段永平 / 巴菲特 复利体系

### 复利公式重构
```
财富 = 本金 × (1 + 收益率)^时间
```
- **本金**：场外现金流（实业分红/薪资/创业收入）是底气
- **收益率**：好商业模式负责（长期持续赚钱、高ROIC）
- **时间**：企业文化负责（不犯致命错误、本分、不作恶）

### 投资铁律
| 原则 | 含义 |
|------|------|
| **买股票 = 买公司** | 看懂商业模式、护城河、管理层诚信、财务真实性 |
| **不熟不投** | 只在认知圈内操作（半导体/AI/消费/周期需深度研究） |
| **安全边际** | 估值打 6-7 折买入，容错空间 |
| **卖出三原则** | ① 买入逻辑消失 ② 估值极度泡沫 ③ 发现更好标的 |

### 7级投资天梯（风险/认知递增）
| 级别 | 工具 | 核心逻辑 |
|------|------|----------|
| L1 现金管理 | 国债逆回购/货币ETF | 底仓防线，季末年化5-10% |
| L2 防御进阶 | 低溢价可转债 | 下有保底(债底)，上不封顶(股性) |
| L3 被动指数 | 沪深300/标普500/红利ETF | 赚国运平均收益，重估值分位定投+止盈 |
| L4 价值选股 | 护城河企业(茅台/腾讯/苹果) | 买公司，看文化，重资本配置能力 |
| L5 周期博弈 | 煤炭/有色/半导体/海运 | 惨淡时布局，狂热时离场 |
| L6 期权工具 | 卖Put降成本/买Call博爆发 | 非线性收益，机构思维跨越关键 |
| L7 反脆弱 | 极小头寸博黑天鹅 | 赔率思维，输得起赢得大 |

## 四、牛散“风生水起”实战准则

### 7不买（避坑）
1. ❌ 放量滞涨 —— 主力出货
2. ❌ 下降通道 —— 趋势为王，不抄底
3. ❌ 大除权后 —— 贴权陷阱
4. ❌ 基本面重大瑕疵 —— 雷股/退市风险
5. ❌ 高位横盘 —— 派发筹码
6. ❌ 利好兑现 —— 利好出尽是利空
7. ❌ 看不懂 —— 认知圈外不碰

### 3不卖（拿住牛股）
1. ✅ 趋势未破不卖 —— 关键均线(EMA20/50)未跌破
2. ✅ 缩量回调不卖 —— 洗盘非出货
3. ✅ 主力未出逃不卖 —— 筹码锁定/大单未流出

### 仓位管理
- **适度集中**：看准重仓（单票≤20%，前5大仓位≥60%）
- **动态平衡**：估值过激/占比过高 → 调仓
- **逆向心法**：别人恐惧我贪婪，克服追涨杀跌本能

## 五、估值方法论

| 方法 | 适用场景 | 关键点 |
|------|----------|--------|
| **DCF(FCF折现)** | 现金流稳定、可预测企业 | 重自由现金流、折现率=无风险+风险溢价 |
| **PEG** | 高增长企业 | PE/增长率 <1 低估，>1.5 高估 |
| **相对估值(PE/PB/PS)** | 同行业可比 | 警惕价值陷阱：低PE可能是夕阳/周期顶 |
| **安全边际** | 所有买入 | 內在价值 × 0.6-0.7 = 买入价 |
