# Skill: 关注股每日分析日报

## 1. 定位
每次用户要求分析A股大盘和自己关注的股票时，严格按照本流程执行，生成**结构一致、数据准确**的日报。

## 2. 铁律

### 【数据真实性】
- **绝对禁止**捏造任何股票的价格、涨跌幅、成交量等数据
- 所有数据必须从 akshare 实时接口获取，不得引用历史会话或记忆中的旧数据
- 如果接口返回空/失败，如实报告，不能编造

### 【关注股票列表的获取方式】
- **每次分析前必须先读取 `analysis_summary_all.md` 文件**，从中提取确切的25只关注股票列表
- **禁止凭记忆、凭MEMORY.md、凭任何其他来源拼凑股票列表**
- `analysis_summary_all.md` 是唯一权威来源

### 【格式约束】
- 用户使用 **webchat** 渠道，支持 Markdown 表格和格式化文本
- 如果推送到其他渠道（如 Telegram），需要去掉表格改用 bullet list

### 【时间标注】
- 分析结果中必须标注数据日期（如"2026年7月17日（周五）收盘数据"）
- 今天是周六/日时，数据是最后一个交易日的快照，必须说明

## 3. 数据获取流程

### Step 1: 读取关注股票列表
```
读取 /Users/duguke/.openclaw/workspace/analysis_summary_all.md
提取 "股票代码 → 股票名称" 的完整映射（目前为24只A股 + 1只B股）
```

### Step 2: 获取实时行情
```
首选: ak.stock_zh_a_spot()      # 新浪接口
备选: ak.stock_zh_a_spot_em()   # 东方财富接口（当前不稳定）

- 新浪接口返回的数据 index 为 'sh代码'/'sz代码'/'bj代码'
- 需要为每个关注股票拼接前缀去匹配
- B股(900925) 不在A股实时行情接口中，报告时标注"B股数据暂不可用"
```

### Step 3: 获取财经新闻
```

```

### Step 4: 大盘指数（可选，当前东方财富接口不稳定）
```

如果失败则通过关注股票的整体涨跌分布推断大盘状态
```

## 5. 分析输出规则

### 分层标准
| 区间 | 标注 | 解读 |
|------|------|------|
| 涨跌幅 > 0% | 🟢 | 相对强势，逆势上涨或抗跌 |
| -3% < 涨跌幅 ≤ 0% | 🟡 | 小幅回调，正常波动区间 |
| -5% < 涨跌幅 ≤ -3% | 🔴 | 深度回调，需关注 |
| 涨跌幅 ≤ -5% | 🚨 | 需警惕，严重回调 |
| 涨跌幅 ≤ -10% | 🚨**跌停** | 极端情况 |

### 操作建议推导原则
- **持有不动**：当天逆势上涨或抗跌（>0%），且基本面未恶化
- **减仓/止损**：跌超5%且伴随利空消息，或跌停
- **等待企稳**：-3% ~ -5% 区间，或下跌但无明显利空
- **加仓机会**：基本面优质标的跌超5%且接近关键支撑位

## 6. 错误处理

| 场景 | 处理方式 |
|------|----------|
| 新浪接口超时 | 等待后重试1次，仍失败则如实报告 |
| 东方财富接口失败 | 不影响个股行情获取，仅新闻部分跳过 |
| B股数据找不到 | 标注"B股数据暂不可用" |
| analysis_summary_all.md 不存在 | 回退读取 MEMORY.md 中 `## User's Stock Watchlist` 章节 |
| 个股数据缺失(如停牌) | 单独标注"停牌/数据暂缺" |
