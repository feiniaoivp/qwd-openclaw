# 每日短线复盘详细检查清单

> 配套 `a-share-review-framework` 技能。标注了执行优先级和时间预算。

---

## 阶段0：昨日交易回顾（5分钟）🔴 不可跳过

- [ ] **计划执行率**：昨日交易计划执行了哪些？未执行的为什么？
- [ ] **计划外操作**：是否有冲动/FOMO操作？原因是什么？
- [ ] **判断复盘**：昨日的核心判断哪些正确？哪些错误？根因是什么？
- [ ] **认知修正**：今天需要修正的1个最重要的认知偏差是什么？

---

## 阶段1：盘前扫描（30分钟）

- [ ] **外围扫描**：美股三大指数 + 中概股 + A50期货 + 日韩早盘
- [ ] **消息面分级**：S级（国家级）/ A级（行业级）/ B级（公司级）+ 预期差判断
- [ ] **昨日情绪定位**：冰点/修复/高潮？杀跌几天？有无补跌信号？
- [ ] **昨日主线复盘**：最强板块 + 涨停梯队 + 各方向所处阶段
- [ ] **核心标的更新**：容量核心名单（每方向1-2只）+ 辨识度个股（≤10只）
- [ ] **指数-个股模式预判**：指数行情 or 个股行情？警惕模式切换信号

---

## 阶段2：竞价分析 9:15-9:25（分级执行）

### 🔴 必做（前5分钟）

- [ ] R1 **致命风险**：核心辨识度票一字跌停封单≥60亿？核心大票≥100亿？
  → 任一触发 = **无条件清仓**，跳过后续所有分析
- [ ] R2 **核心中军竞价**：各方向容量中军涨跌幅。有无≤-3%？是否连续杀跌例外？
- [ ] R3 **跌停全景**：全市场一字跌停总家数+总封单量+集中方向

### 🟡 选做（后5分钟，时间不够可跳过）

- [ ] S1 **一字板封单**：总封单量 + 方向集中度 + 与近期均值对比
- [ ] S2 **竞价异动**：最后几分钟板块性大单拉升/砸盘
- [ ] S3 **封单方向切换**：对比昨日封单方向，是否切换？
- [ ] **竞价推演**：3种情景（含验证条件），1分钟内完成

---

## 阶段3：开盘验证 9:30-10:00

- [ ] **预期兑现检验**：各方向走势 vs 竞价推演
- [ ] **兑现盘观察**：高开方向是否被砸？承接力度？
- [ ] **跷跷板验证**：A强→B是否如期弱？"该弱不弱"=超预期
- [ ] **量能结构预估**：前30分钟→全天预估。权重集中 or 中小票分散？

---

## 阶段4：盘中博弈 10:00-14:30

- [ ] **分歧哨兵**：龙头炸板时间 / 批量炸板 → 关注卡位方向
- [ ] **资金卡位**：分歧时哪个方向拉升？→ 新跟踪方向
- [ ] **赚钱效应**：20cm涨停数 / 弹性标的 / 北交所活跃度
- [ ] **下午确认**：上午强→下午加强/回落？上午弱→下午转强？→ 定次日基调
- [ ] **题材轮动节奏**：全天各方向切换顺序
- [ ] **尾盘异动**：最后30分钟抢筹 or 砸盘方向

---

## 阶段5：收盘汇总 15:00后

- [ ] **涨停梯队**：最高板 / 各连板数 / 晋级率 / 炸板率
- [ ] **板块排名**：Top5涨停家数 + 资金净流入 + 涨幅 → 交叉验证
- [ ] **市场宽度**：涨跌比 / 涨幅中位数
- [ ] **资金面**：北向净流入 / 两市成交额 / 龙虎榜
- [ ] **流动性结构**：Top20市值分布（权重vs小票）+ Top3板块成交额占比（集中vs分散）

---

## 阶段6：市场健康度评分

逐项打分（每项1-10分）计算加权总分：

- [ ] 涨停梯队完整度（20%）：__/10 × 0.20 = ____
- [ ] 晋级率（15%）：__/10 × 0.15 = ____
- [ ] 炸板率（15%）：__/10 × 0.15 = ____
- [ ] 市场宽度（15%）：__/10 × 0.15 = ____
- [ ] 量能（vs前5日均值）（15%）：__/10 × 0.15 = ____
- [ ] 主线持续性（10%）：__/10 × 0.10 = ____
- [ ] 负反馈程度（10%）：__/10 × 0.10 = ____

**总评分：__/10**（上日__/10，变化____）

---

## 阶段7：隔日推演 + 交易计划

- [ ] **市场阶段定位**：上升/震荡/下跌
- [ ] **情绪周期定位**：冰点/修复/高潮
- [ ] **主线vs轮动判断**：有无共振主线？
- [ ] **方向A概率推演**：情景1(__%) + 情景2(__%) + 情景3(__%) = 100%
- [ ] **方向B概率推演**：同上
- [ ] **仓位计划**：按仓位矩阵确定总仓位上限 + 分配到各方向
- [ ] **风险预警**：潜在退潮方向 + 止损条件
