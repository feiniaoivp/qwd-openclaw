# 竞价分析 —— 9:26-9:29 快速决策

## 定位

本技能是030复盘体系中"阶段1+阶段2"的精华提取版，专为竞价结束后、开盘前的3分钟黄金窗口设计。**目标不是全面分析，而是快速回答三个问题：有没有致命风险？有没有机会？怎么操作？**

## 前置条件

在9:15竞价开始前，必须已完成：
- 昨日市场阶段和情绪位置判断
- 隔夜消息面扫描（S/A/B级 + 预期差判断）
- 核心观察标的名单更新（容量核心 + 辨识度个股，15-20只）
- 外围市场映射（美股、中概股、A50、日韩）

⚠️ 如果前置条件未完成，本技能输出将不完整。盘前准备应提前到8:00-9:15完成。

## 🔴 第一步：致命风险扫描（9:26，第1分钟）

**在分析任何机会之前，先排除致命风险。这是铁律。**

### 致命风险（任一触发 → 无条件清仓 + 不参与当日交易）

| 检查项 | 阈值 | 怎么看 |
|-------|------|--------|
| 核心辨识度票一字跌停 | 封单 ≥ 60亿 | 短线侠竞价封单 / 通达信跌停板封单 |
| 核心大票一字跌停 | 封单 ≥ 100亿 | 同上 |
| 多个近期辨识度标的同时一字跌停 | ≥ 2只 | 扫描核心观察名单 |

> 任一触发 → **输出「致命风险：停止交易」+ 清仓指令，跳过后续所有分析。**

### 高风险防御（触发 → 不开新仓 + 设止损）

| 检查项 | 例外 | 操作 |
|-------|------|------|
| 任一核心容量中军竞价 ≤ -3% | 连续2日以上杀跌 → 视为机会 | 不开新仓，持仓设-5%止损 |
| 全市场一字跌停 ≥ 5家 | — | 不开新仓 |
| 核心标的所在板块出现批量低开-3%以上 | — | 该方向不参与 |

## 第二步：机会方向识别（9:27，第2分钟）

**只有风险检查通过后，才开始找机会。**

### 信号1：封单方向集中度（最强信号）

查看竞价一字板封单集中在哪个方向：
- **集中在一个方向 + 封单总量远超近期均值（如30亿→200亿+）** → 该方向有情绪质变，重点关注
- **分散在多个方向** → 混沌，没有明确主线，降低预期
- **封单方向与前一日不同** → 方向切换，原方向可能被抽血

### 信号2：竞价异动（板块性）

看竞价最后几分钟（9:20-9:25）是否有板块性的大单拉升：
- **同一方向多只标的集体拉升** → 资金意图明确，大概率开盘延续
- **仅个别标的异动** → 个股行为，不构成方向信号

### 信号3：跷跷板预判

基于封单方向 + 外围映射，预判：
- 哪些方向开盘会走强？
- 它们的跷跷板对手方（前一日强势方向）是否会走弱？
- **需要重点观察的关键信号**：若跷跷板对手方"该弱不弱"→ 这是盘中超预期机会

### 信号4：容量中军竞价确认

核心方向的大票竞价表现：
- **中军竞价强势（+3%以上）+ 封单方向一致** → 方向确认度高
- **中军高开但封单不匹配** → 警惕兑现，不追高
- **中军低开但封单强** → 可能只是开盘分歧，关注开盘后是否被拉回

## 第三步：量能预估（9:28，第3分钟前半）

基于竞价阶段的成交量和封单量，预估今日全天量能方向：
- **竞价成交量明显放大（对比前5日同期）** → 今日大概率放量
- **竞价成交量萎缩** → 缩量震荡预期

快速判断量能是否支持当前机会方向：
- 如果封单200亿+但竞价成交萎缩 → 封单可能虚假，开盘容易兑现
- 如果封单正常+竞价成交放大 → 方向可靠度提升

## 信号冲突裁决

竞价阶段常见冲突及裁决：

| 冲突 | 裁决 | 理由 |
|------|------|------|
| 封单200亿（看多） vs 中军≤-3%（看空） | **看空** | 负反馈 > 封单信号 |
| 封单集中（看多） vs 跌停家数多（看空） | **看空** | 负反馈 > 封单信号 |
| 外围利好 vs 竞价封单不及预期 | **降预期** | 内盘竞价 > 外盘映射 |
| 多个方向都有封单（分散） vs 其中一个封单最大 | **关注最大封单方向** | 分散中找相对集中 |

核心原则：**宁可错过，不可做错。不确定时选择防守。**
