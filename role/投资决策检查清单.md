# 投资决策检查清单

> 版本：v1.0 | 更新：2026-08-30 | 来源：wiki/sources 知识库四大核心文件
> 用途：**每笔交易前必须逐项勾选**，未通过项 = 不执行

---

## 📋 使用说明

| 场景 | 适用清单 |
|------|----------|
| **新开仓（买入）** | 全清单 §A + §B + §C + §D |
| **加仓** | §A(核心) + §B + §C |
| **减仓/止盈** | §C + §D |
| **止损/离场** | §D (无条件执行) |
| **持仓复盘（周末/月度）** | §A + §B + §E |

> ⚠️ **铁律**：任何单项出现 ❌ = **直接放弃/执行止损**，不接受妥协、不找理由、不“再观察一下”

## §A 认知圈与非对称性检查（准入门槛）

| # | 检查项 | 判定标准 | ✅/❌ |
|---|--------|----------|------|
| A1 | **看懂赚钱逻辑** | 能否用 **3句话** 讲清：靠什么赚钱？护城河是什么？风险在哪？ | ☐ |
| A2 | **认知圈内操作** | 是否在已深度研究的行业/模式内？（超出圈外 → ❌ 或极小仓位≤1%） | ☐ |
| A3 | **非防御性拒绝** | 是否在用“防电诈逻辑”拒绝投资？（识别：恐惧驱动 vs 理性分析驱动） | ☐ |
| A4 | **先相信后看见** | 是否已在“看见前”完成调研建仓？（等看见了才信 → 已晚，❌） | ☐ |
| A5 | **Skin in the Game** | 管理层/大股东/自己是否真金白银绑定？（无利益绑定 → ❌） | ☐ |
| A6 | **机制>道德** | 核心逻辑依赖：代码/数学/激励结构/垄断/品牌 —— **而非** “人好/专家推荐/热点” | ☐ |

> **通过标准**：A1-A6 **全 ✅** 才可进入 §B

## §B 基本面/护城河验证（质地确认）

| # | 检查项 | 判定标准 | ✅/❌ |
|---|--------|----------|------|
| B1 | **护城河评分 ≥ 60** | 晨星五基因打分：品牌/转换成本/网络效应/成本优势/有效规模 ≥ 60/100 | ☐ |
| B2 | **ROE/IC 持续 > 15%** | 近 3-5 年 ROE 与 ROIC 均 > 15%，且无大幅下滑 | ☐ |
| B3 | **现金流健康** | 经营现金流持续为正，FCF > 净利润（不靠应收账款撑利润） | ☐ |
| B4 | **无重大隐患** | 无财务造假、无关联交易输血、无大股东质押>50%、无行业政策致死风险 | ☐ |
| B5 | **管理层资本配置能力** | 分红/回购/再投资/并购历史验证：ROIC > WACC，不盲目扩张 | ☐ |
| B6 | **安全边际充足** | 当前价格 ≤ 內在价值 × 0.7（DCF/PEG/相对估值三法取交集） | ☐ |

> **通过标准**：B1-B6 **≥ 5 项 ✅**（B2/B3/B4 为硬性必过）

## §C 技术面/趋势验证（时机确认）—— 仅白名单指标

> 依据：`wiki/sources/technical-analysis-core.md` 指标白名单

| # | 检查项 | 判定标准 | ✅/❌ |
|---|--------|----------|------|
| C1 | **大趋势向上** | 月线/周线 EMA200 向上，价格在上方（月线级别多头排列） | ☐ |
| C2 | **中趋势健康** | 日线 EMA50 向上，价格 > EMA50，EMA20 > EMA50 > EMA200（多头排列） | ☐ |
| C3 | **触发信号（任一）** | ① 回踩 EMA20/EMA50 企稳（缩量+锤子/吞没）<br>② MACD 零轴上金叉<br>③ 压力位放量突破 + 回踩确认（极性转换）<br>④ EMA8/21/50 回踩买入区 + 放量 | ☐ |
| C4 | **成交量配合** | 入日放量 > 近20日均量 1.5倍；回调缩量 < 0.6倍 | ☐ |
| C5 | **MACD 零轴分多空** | MACD 线与信号线均在零轴上方（多头区）；无顶背离 | ☐ |
| C6 | **支撑压力位置** | 距强支撑 < 5%（安全垫）；距强压力 > 8%（上行空间） | ☐ |
| C7 | **斐波那契共振（加分）** | 0.5/0.618 回撤位与 水平支撑/EMA50 重合（非必需，有则加分） | ☐ |

> **通过标准**：C1+C2+C3(任一)+C4+C5 **全 ✅**；C6 为参考；C7 加分

## §D 风控与执行纪律（生存铁律）

| # | 检查项 | 判定标准 | ✅/❌ |
|---|--------|----------|------|
| D1 | **硬止损已设** | 入场同一秒挂出止损单：**min(前低, EMA20下2%, 2×ATR)**，绝不移动扩大 | ☐ |
| D2 | **盈亏比 ≥ 1:2** | (目标位 - 入场价) / (入场价 - 止损价) ≥ 2；否则 ❌ | ☐ |
| D3 | **单笔风险 ≤ 1%** | 单票最大亏损 ≤ 总资金 1%（含手续费滑点） | ☐ |
| D4 | **单票上限 ≤ 20%** | 单只股票仓位 ≤ 总资金 20% | ☐ |
| D5 | **组合风险 ≤ 6%** | 同时在险仓位总和 ≤ 总资金 6% | ☐ |
| D6 | **分批建仓** | 首仓 50%，盈利 1R 加仓 25%，再盈利 1R 加仓 25%（金字塔） | ☐ |
| D7 | **分批止盈** | TP1: 前高/1.0扩展位 减仓 30%<br>TP2: 1.272-1.618扩展位 减仓 50%<br>TP3: MACD零轴下死叉/跌破EMA50 清仓 | ☐ |
| D8 | **情绪状态确认** | 当下平静、不贪不恐、可随时无犹豫执行止损（否则 ❌ 暂停操作） | ☐ |
| D9 | **计划单已写** | 入场价、止损价、目标位、加减仓规则、复盘节点 —— 全部书面化 | ☐ |

> **通过标准**：D1-D9 **全 ✅**（D1/D2/D3 为绝对红线）

## §E 持仓复盘清单（周末/月度必做）

| # | 检查项 | 执行动作 |
|---|--------|----------|
| E1 | **买入逻辑存续** | 原买入理由（基本面/技术面）是否仍然成立？逻辑消失 → 启动卖出三原则 | 
| E2 | **估值泡沫化** | PEG > 1.5 或 PE/PB 达历史 90% 分位 → 分批止盈 |
| E3 | **发现更好标的** | 新标的综合评分显著高于现有持仓 → 调仓置换 |
| E4 | **趋势结构破坏** | 周线跌破 EMA50 或月线跌破 EMA200 → 强制减仓 50%+ |
| E5 | **量价背离持续** | 连续 3 周价涨量缩/价跌量增 → 警惕反转，收紧止损 |
| E6 | **宏观环境变化** | 利率/汇率/政策/行业周期发生根本性转向 → 重评仓位结构 |
| E7 | **策略映射更新** | 每周六 `weekly-backtest-pipeline` 后，同步更新 `adaptive_strategy_map.json` |

```
开始新交易
    │
    ▼
§A 认知圈检查 ──❌──→ 直接放弃
    │
   ✅│
    ▼
§B 护城河验证 ──❌(硬指标不过)──→ 直接放弃
    │
   ✅│
    ▼
§C 技术触发确认 ──❌──→ 等待/放弃，不强行入场
    │
   ✅│
    ▼

   ✅│

    │
    ▼

```

## ⚡ 紧急情况处理预案

| 突发情况 | 处理动作 |
|----------|----------|
| **闪崩/跌停打开** | 止损单自动成交；不补仓、不摊薄；事后复盘 §E |
| **利空突发（财务造假/政策突变）** | 即时市价清仓，不等反弹，不讲成本价 |
| **止损单未成交（流动性枯竭）** | 分笔市价单离场，接受滑点，命大于本 |
| **情绪失控（连续止损/暴利后亢奋）** | 强制休市 1-3 天，清空持仓观察，重置心态 |
| **系统性风险（大盘周线破年线）** | 全仓降至 ≤ 30%，仅保留宽护城河+现金流极佳核心仓位 |
